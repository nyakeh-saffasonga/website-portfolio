## Instructions

- 1. Go to the terminal and type in "npm i" and run it. 
- 2. After it finishes running, ensure a folder named node_modules is created by the commnd
- 3. Type in "npm start" into the terminal and run it.
- 4. Go to http://http://localhost:3000/ and test put the page!
